# Lab 5.3: Copilot Pages

**Leitfragen:**

<details>
<summary>Wann nimmt man eine Page statt eines Chat-Verlaufs?</summary>

Sobald ein Ergebnis über den aktuellen Chat hinaus weiterverwendet, überarbeitet oder mit anderen geteilt werden soll.

</details>

<details>
<summary>Wer sieht eine geteilte Page und wer einen geteilten Prompt?</summary>

Eine geteilte Page sehen alle, mit denen sie freigegeben wurde, im jeweils aktuellen Bearbeitungsstand. Ein geteilter Prompt aus dem Promptkatalog ist für andere direkt verwendbar, ohne dass diese den Erstellungsweg nachvollziehen müssen.

</details>

<details>
<summary>Warum lohnt es sich, gute Prompts im Team zu teilen?</summary>

Ein einmal ausgearbeiteter, präziser Prompt spart anderen die eigene Optimierungsrunde und sichert einheitliche Ergebnisqualität im Team.

</details>

- Ein Chat-Verlauf ist flüchtig und linear; eine Page ist ein persistentes, strukturierbares Arbeitsdokument.
- Pages und gespeicherte Prompts lassen sich mit anderen teilen, ein einzelner Chat-Verlauf nicht ohne Weiteres.

## Chat-Verlauf vs. Page

| Kriterium          | Chat-Verlauf                             | Copilot Page                          |
| ------------------ | ---------------------------------------- | ------------------------------------- |
| Struktur           | linearer Frage-Antwort-Verlauf           | frei strukturierbares Dokument        |
| Persistenz         | bleibt im Chat-Verlauf erhalten          | eigenständiges, editierbares Artefakt |
| Teilen             | nicht für gemeinsame Bearbeitung gedacht | direkt teilbar, gemeinsam bearbeitbar |
| Weiterverarbeitung | Copy-Paste aus dem Verlauf nötig         | Inhalte direkt in der Page ergänzbar  |

> **[SCREENSHOT-PLATZHALTER – Quelle erforderlich]** UI-Pfad: Copilot Chat → "In Page öffnen"/Page-Ansicht mit Teilen-Option. Ersetzen durch eigene anonymisierte Sandbox-Aufnahme (mit Aufnahmedatum) oder offizielle Microsoft-Learn-Abbildung (mit Quelle und Datum).

> **Merksatz:** Ein Chat-Verlauf beantwortet eine Frage, eine Page hält ein Ergebnis fest.

## Prompts speichern und teilen

- Ein bewährter Prompt lässt sich im Promptkatalog ablegen und mit dem Team teilen.
- Geteilte Prompts sparen Kolleg:innen die eigene Optimierungsrunde aus Modul 2.
- Ein geteilter Prompt bleibt unabhängig von seinem ursprünglichen Chat-Verlauf nutzbar.

## Grenzen

- Eine Page ersetzt kein Dokumentenmanagement-System; sie ist für schnelle, gemeinsame Arbeitsergebnisse gedacht.
- Freigaben folgen denselben Berechtigungen wie andere M365-Inhalte — keine automatische Sichtbarkeit für alle.

## Fazit

- Pages halten Ergebnisse fest, die über einen einzelnen Chat hinaus gebraucht werden.
- Geteilte Prompts verbreiten geprüfte Formulierungen im Team, statt sie jedes Mal neu zu erfinden.
- Freigabe folgt bestehenden Berechtigungen, nicht automatischer Offenheit.

Die Übung überführt das Ergebnis aus Lab 5.1 in eine Page und teilt einen Prompt daraus.
