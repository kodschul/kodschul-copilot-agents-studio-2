# Lab 1.0 – Übung: Prompt, besserer Prompt oder Agent?

**Ändert die Nordwind-Projektbasis?** Nein — produktunabhängige Einordnungsübung vor dem Copilot-Teil.

## Ausgangslage

Nordwind Consulting prüft, wo KI-Unterstützung im Alltag sinnvoll ist. Fünf typische Situationen aus dem Beratungsalltag liegen als Kurzszenarien vor (`szenarien.md` in den Kursunterlagen).

Die fünf Szenarien:

1. Ein 40-seitiges Ausschreibungsdokument soll auf die drei wichtigsten Anforderungen reduziert werden.
2. Jede Woche fragen neue Mitarbeitende dieselben fünf Fragen zur Reisekostenabrechnung.
3. Eine Absage an einen Bewerber soll formuliert werden, der Entwurf klingt bisher unpersönlich und zu hart.
4. Aus einer Budget-Tabelle sollen einmalig die drei größten Kostenblöcke benannt werden.
5. Das Support-Team beantwortet täglich Fragen zur internen IT-Richtlinie, die sich selten ändert.

## Aufgaben

1. Jedes der fünf Szenarien genau einer Stufe zuordnen: "braucht nur einen Prompt", "braucht einen besseren Prompt" oder "braucht einen Agenten".
2. Die Zuordnung je Szenario mit einem Satz begründen; das Kriterium benennen, das die Entscheidung getragen hat (Wiederholung? feste Wissensquelle? Qualitätsanspruch?).
3. Für das Szenario, das als "braucht einen besseren Prompt" eingeordnet wurde: aufschreiben, welche konkrete Angabe im Prompt fehlt.
4. Ein eigenes Szenario aus dem Arbeitsalltag ergänzen und ebenfalls einordnen.

## Checkpoint

- Alle fünf Szenarien sind zugeordnet, keine Doppelzuordnung, keine Lücke.
- Zu mindestens einem Szenario ist notiert, welche Prompt-Angabe konkret fehlt (nicht "mehr Details").
- Das eigene sechste Szenario ist benannt und eingeordnet.

## Abschlusskriterien

- Eine schriftliche Liste mit sechs Zeilen liegt vor: Szenario, Stufe, Begründung.
- Das Kriterium "Wiederholung + feste Wissensquelle" kann als Agenten-Merkmal benannt werden.

## Erweiterung

Für das eigene sechste Szenario zusätzlich notieren, welche Wissensquelle ein Agent bräuchte und wer sie pflegen müsste.
