# Lab 1.1: Copilot Vision & Use Cases

**Leitfragen:**

<details>
<summary>Welche Aufgaben im Arbeitsalltag sind überhaupt Copilot-tauglich?</summary>

Aufgaben mit viel Text, wiederkehrender Struktur und vorhandenem Kontext in M365: Zusammenfassen, Entwerfen, Umformulieren, Strukturieren, Daten erklären.

</details>

<details>
<summary>Woran erkennt man einen Anwendungsfall, bei dem Copilot mehr Arbeit macht als spart?</summary>

Wenn die Prüfung des Ergebnisses länger dauert als die Aufgabe selbst — typisch bei kurzen Texten, exakten Zahlen und rechtlich verbindlichen Formulierungen.

</details>

- Microsoft 365 Copilot ist eine Funktionsschicht in den bereits genutzten Apps, kein eigenständiges Programm.
- Der Einsatz lohnt sich für manche Aufgaben, für andere nicht.

## Wo Copilot auftaucht

| Ort          | Typischer Nutzen                                           |
| ------------ | ---------------------------------------------------------- |
| Word         | Entwurf aus Vorlage/Quelle, Umschreiben, Zusammenfassen    |
| PowerPoint   | Gliederung und Foliengerüst, Sprechnotizen                 |
| Excel        | Daten erklären, Formeln vorschlagen, Auffälligkeiten       |
| Outlook      | Entwürfe, Verlaufs-Zusammenfassung, Tonanpassung           |
| Teams        | Meeting-Zusammenfassung, Aktionspunkte, Chat-Recap         |
| Copilot Chat | app-übergreifender Einstiegspunkt für mehrstufige Aufgaben |

![Screenshot of the Copilot Dynamic Action button and suggested user actions](https://support.microsoft.com/en-us/office/media/copilot-dynamic-action-in-word-excel-and-powerpoint-apps.jpg)

## Das Lizenzmodell in einem Satz

| Variante              | Kurzbeschreibung                                                          |
| --------------------- | ------------------------------------------------------------------------- |
| Copilot Chat          | browserbasierter Chat, ohne Zugriff auf die eigenen Arbeitsdokumente      |
| Microsoft 365 Copilot | kostenpflichtige Lizenz, direkt in den Apps, mit Zugriff auf eigene Daten |

Der Vergleich im Detail folgt in Lab 1.3.

## Nutzenmuster statt Toolliste

| Muster        | Beispiel bei Nordwind Consulting               | Zeitgewinn entsteht durch     |
| ------------- | ---------------------------------------------- | ----------------------------- |
| Verdichten    | 40-seitige Ausschreibung auf Kernanforderungen | Lesezeit                      |
| Entwerfen     | erster Entwurf des Kundenangebots              | Startpunkt statt leeres Blatt |
| Umformulieren | interner Text wird kundentauglich              | Überarbeitungsrunden          |
| Strukturieren | ungeordnete Notizen werden Gliederung          | Sortieraufwand                |
| Erklären      | fremde Excel-Formel verständlich machen        | Einarbeitung                  |

> **Merksatz:** Copilot spart beim ersten Entwurf und beim Verdichten, nicht beim Prüfen. Der Prüfaufwand bleibt und verschiebt sich nur nach hinten.

## Wo es sich nicht lohnt

- Sehr kurze Texte: der Prompt dauert länger als das Schreiben.
- Exakte Zahlen und Fristen: müssen ohnehin vollständig nachgerechnet werden.
- Rechtlich verbindliche Formulierungen: Freigabe bleibt bei der Fachabteilung.
- Aufgaben ohne Kontext in M365: fehlt die Datengrundlage, bleibt die Antwort generisch.

## Fazit

- Copilot ist eine Schicht in bekannten Apps, kein zusätzliches Werkzeug im Werkzeugkasten.
- Der Nutzen liegt bei Verdichten, Entwerfen, Umformulieren, Strukturieren und Erklären.
- Der Prüfaufwand verschwindet nicht; er entscheidet darüber, ob sich ein Anwendungsfall lohnt.

In der Übung werden eigene Anwendungsfälle gesammelt und nach diesem Maßstab bewertet.
